## 1. Функциональная карта «что уже есть / что дополняем» (п. 5.1)

| Функция | «Мобильное ТОРО» | «ТОРО-Ассистент» |
|---|---|---|
| Регистрация дефекта, фото, сообщение М2 | есть | не дублируем; берём дефект как вход |
| Обходы, электронные чек-листы, заказы на осмотр | есть | не дублируем |
| Офлайн-режим | есть (регистрация) | офлайн-**анализ** и рекомендации |
| Синхронизация с SAP ТОРО | есть | своя очередь; решение уходит как М2 с трассировкой |
| Фактические параметры техники | в диспетчерской системе, разрозненно | сводим в карточку и сравниваем с порогами модели |
| История отказов | копится в ТОРО | используем: поиск похожих случаев |
| Интеллектуальная поддержка решений | **нет** | **основная зона развития** |
| «Данных недостаточно — нужен такой-то замер» | нет | есть |
| Запрет автономного допуска при критичных отказах | — | встроен в ядро |

## 3. TO-BE с «ТОРО-Ассистентом» (п. 5.3)

## 4. Шаблон сравнения AS-IS / TO-BE (п. 7)

| Этап | AS-IS, мин | TO-BE, мин | Источник эффекта |
|---|---|---|---|
| Получение данных | | | автоподтягивание параметров |
| Поиск документации | | | офлайн-справочник |
| Первичная диагностика | | | правила + похожие случаи |
| Консультация | | | объяснимая рекомендация |
| Дополнительные проверки | | | только информативные замеры |
| Принятие решения | | | статус и доступные решения |
| **Итого** | | | |

**Показатели:**
- ΔT_реш = T_AS-IS − T_TO-BE;
- K_T = ΔT_реш / T_AS-IS × 100 %.

**Что считать по журналу в пилоте:**
- доля случаев, в которых агент корректно запросил данные;
- согласие специалиста с первой причиной (`agreesWithAgent`);
- число повторных анализов на один дефект;
- время от `DEFECT_CREATED` до `DECISION_CONFIRMED`.

Журнал уже собирает все эти поля — **метрики пилота доступны без доработок**.

## 5. Экономический шаблон (п. 8)

Расчёт делает отдельная команда. Шаблон с формулами — `tools/economics.py`, входные данные — `templates/economics.template.json`. Числа в шаблоне пустые:
- E_пр = Σ(ΔTᵢ × Cᵢ);
- E_год = E_пр + E_труд + E_повтор − OPEX;
- T_ок = CAPEX / E_год, при условиях T_ок ≤ 5 лет и срок внедрения ≤ 12 мес.
